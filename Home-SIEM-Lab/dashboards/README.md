Home SIEM Dashboard 

Overview 

A Splunk Classic Dashboard created to monitor Windows Security and Sysmon events collected in the Home SIEM Lab. 

Dashboard Panels :
1. Total Failed Logins 
2. Total Successful Logins 
3. Total Process Creations 
4. Total DNS Queries 
5. Event Distribution by Log Source (Pie Chart) 
6. Event Counts by Log Source 
7. Login Events Over Time
