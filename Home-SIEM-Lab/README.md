Home SIEM Lab — Splunk 

Overview 

A beginner-level SIEM home lab built using Splunk Enterprise on Windows 10 to collect, monitor, and analyze Windows and Sysmon event logs. 

Tools Used:
1. Splunk Enterprise 
2. Splunk Universal Forwarder 
3. Sysmon 
4. Windows 10 
5. SPL (Search Processing Language) 

Key Features :
1. Windows log collection and monitoring 
2. Failed and successful login detection 
3. Sysmon process creation monitoring 
4. DNS query monitoring 
5. SPL-based event analysis 
6. Custom Splunk Classic Dashboard 

Dashboard :
Created a centralized dashboard to visualize authentication activity, process events, DNS queries, and log source distribution.  

Project Structure :
screenshots/ — Project evidence 
detection/ — SPL queries and detection searches 
dashboard/ — Dashboard documentation and screenshots 

Skills Demonstrated :
Splunk, Windows Event Logs, Sysmon, SPL, Security Monitoring, and SIEM Dashboard Development.
