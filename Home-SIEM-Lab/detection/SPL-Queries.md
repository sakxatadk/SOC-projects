Home SIEM Lab — SPL Queries 
Project Information 
Project: Home SIEM Lab — Splunk 
Platform: Splunk Enterprise 
Operating System: Windows 10 
Index: windows 
Log Sources: Windows Security, System, Application, Firewall, and Sysmon 

This document contains the SPL queries used for log monitoring, authentication monitoring, process creation monitoring, DNS monitoring, and dashboard creation. 

1. Log Source Overview 
Purpose: Identify the different log sources and sourcetypes collected in Splunk. 

index=windows 
| stats count by source sourcetype 
| sort - count 

2. Sysmon Event ID Overview 
Purpose: Identify the types and frequency of Sysmon events collected. 

index=windows sourcetype="XmlWinEventLog:Microsoft-Windows-Sysmon/Operational" 
| stats count by EventID 
| sort - count 

3. Windows Security Events 
Purpose: Review the Windows Security event codes collected in Splunk. 

index=windows sourcetype="WinEventLog:Security" 
| stats count by EventCode 
| sort - count 

4. Failed Login Detection 
Event ID: 4625 
Purpose: Identify unsuccessful Windows login attempts. 

index=windows sourcetype="WinEventLog:Security" EventCode=4625 
| table _time ComputerName Account_Name Logon_Type Status Sub_Status Source_Network_Address 
| sort - _time 

5. Successful Login Detection 
Event ID: 4624 
Purpose: Monitor successful Windows login events. 

index=windows sourcetype="WinEventLog:Security" EventCode=4624 
| table _time ComputerName Account_Name Logon_Type Source_Network_Address 
| sort - _time 

6. Sysmon Process Creation Monitoring 
Event ID: 1 
Purpose: Monitor newly created processes and their execution details. 

index=windows sourcetype="XmlWinEventLog:Microsoft-Windows-Sysmon/Operational" EventID=1 
| table _time User Image CommandLine ParentImage ParentCommandLine ProcessId 
| sort - _time 

7. Sysmon DNS Query Monitoring 
Event ID: 22 
Purpose: Monitor DNS queries generated by applications. 

index=windows sourcetype="XmlWinEventLog:Microsoft-Windows-Sysmon/Operational" EventID=22 
| table _time User Image QueryName QueryResults 
| sort - _time 

Dashboard Queries 
The following searches are used by the Home SIEM Dashboard. 
8. Total Failed Logins 

index=windows sourcetype="WinEventLog:Security" EventCode=4625 
| stats count AS "Total Failed Logins" 

9. Total Successful Logins 

index=windows sourcetype="WinEventLog:Security" EventCode=4624 
| stats count AS "Total Successful Logins" 

10. Total Process Creations 

index=windows sourcetype="XmlWinEventLog:Microsoft-Windows-Sysmon/Operational" EventID=1 
| stats count AS "Total Process Creations" 

11. Total DNS Queries 

index=windows sourcetype="XmlWinEventLog:Microsoft-Windows-Sysmon/Operational" EventID=22 
| stats count AS "Total DNS Queries" 

12. Event Distribution by Log Source 

index=windows 
| stats count by sourcetype 
| sort - count 

13. Event Counts by Log Source 

index=windows 
| stats count by sourcetype 
| sort - count 

14. Login Events Over Time 

index=windows sourcetype="WinEventLog:Security" (EventCode=4624 OR EventCode=4625) 
| timechart span=1h count by EventCode 


Notes 
All searches use the windows index. 
Windows Event ID 4625 represents failed login attempts. 
Windows Event ID 4624 represents successful login events. 
Sysmon Event ID 1 records process creation. 
Sysmon Event ID 22 records DNS queries. 
Some fields may be empty when they are not present in an event. 

Project Outcome 
This project demonstrates basic SIEM monitoring using Splunk Enterprise, including Windows event collection, authentication monitoring, Sysmon process and DNS monitoring, SPL searches, and dashboard visualization.
